# 中学受験 国語ドリル（印刷用PDF）

中学受験の国語の **暗記分野** と、**長文読解の消去法トレーニング** を、すべて印刷できるPDFで作るアプリです。
**すべて入試と同じ縦書き**（右から左へ読む組み方）で、A4横向きに印刷します。
作成済みのPDFは `pdf/` に入っているので、そのまま印刷して使えます。

## 収録内容

### 暗記分野（`pdf/暗記分野/`）
各分野のPDFは「暗記シート → テスト第1〜3回（各回の直後に解答）」の順です。

| 分野 | 問題数 | テスト形式 |
| --- | --- | --- |
| 漢字の書き取り | 105 | カタカナを漢字に（20問） |
| 漢字の読み | 100 | 読みをひらがなで（20問） |
| 四字熟語 | 42 | 意味をヒントに□をうめる（15問） |
| ことわざ | 40 | 意味に合うように（　）をうめる（15問） |
| 慣用句 | 38 | 同上（15問） |
| 故事成語 | 23 | 同上・読みつき（15問） |
| 対義語 | 40 | □に漢字一字（20問） |
| 類義語 | 32 | □に漢字一字（20問） |
| 同音異義語・同訓異字 | 20組 | 文に合う漢字を書く（同じ読みの組ごとに出題） |
| 敬語 | 23 | 尊敬語・謙譲語・丁寧語に直す（15問） |
| 総合テスト | ― | 全分野から2問ずつ |

- **暗記シート**は答えが朱色で印刷されるので、**赤シートでかくして**覚えられます。
- テストは1問が1本の短冊（上に問題、下に解答らん）で、1回分が1枚に収まります。左はしに日付・名前・得点のらんがあります。

### 授業プリント（`pdf/授業プリント/`）
1回の授業（90分）でそのまま配れる1冊です。**全15回**で、回ごとに長文が1題ずつ変わります。

| 回 | 長文 | 語句テスト |
| --- | --- | --- |
| 1 | 物語文「最後の一区間」 | ことわざ・慣用句 |
| 2 | 物語文「かめの中の時間」 | 四字熟語 |
| 3 | 説明文「ふまれて生きる草」 | 対義語・類義語 |
| 4 | 論説文「迷うことの意味」 | 故事成語・ことわざ |
| 5 | 物語文「指揮棒の重さ」 | 同音異義語・同訓異字 |
| 6 | 説明文「ダンゴムシの曲がり角」 | 敬語・慣用句 |
| 7 | 物語文「緑色の空」 | ことわざ・慣用句 |
| 8 | 論説文「『わからない』と言える力」 | 四字熟語 |
| 9 | 物語文「兄のスパイク」 | 対義語・類義語 |
| 10 | 説明文「ミツバチのダンス」 | 故事成語・ことわざ |
| 11 | 物語文「ひまわりの観察日記」 | 同音異義語・同訓異字 |
| 12 | 論説文「ことばの温度」 | 敬語・慣用句 |
| 13 | 説明文「森は海を育てる」 | ことわざ・慣用句 |
| 14 | 物語文「一番星」 | 四字熟語 |
| 15 | 論説文「失敗という情報」 | 対義語・類義語 |

- 漢字テストは毎回「書き取り10問＋読み10問」。語句テストは6回で一めぐりするように分野を入れかえます。
- 問題は分野ごとにシャッフルして先頭から順に使うので、問題が一巡するまでは同じ問題は出ません。漢字は第11回ごろから、前に出た問題の復習が入ります。

- **生徒用**：表紙（今日のめあて・授業の流れと時間配分・得点らん・ふり返り）→ 漢字テスト20問 → 語句テスト（約15問）→ 消去法の解き方ガイド → 長文の本文 → 問一〜問三の消去法ワークシート
- **先生用**（後ろにまとめてあるので切りはなして使えます）：二つのテストの解答 → 長文の解答・解説 → 根拠に網かけした解答用本文

```sh
python3 generate.py lesson --lesson 1     # 第1回だけ作る
```

### 長文読解 消去法トレーニング（`pdf/長文読解/`）
本文はすべてこの教材のための書き下ろし（物語文7・説明文4・論説文4の15題、各3問）。1題ごとに次の順で入っています。

1. **消去法の解き方ガイド**（4ステップと「×の種類」A〜F）
2. **本文**：入試と同じ縦書き・行番号つき（5行ごと）・傍線部①②③
3. **設問＋消去法ワークシート**（1問1ページ）
   - STEP1 傍線部が何行目か → **前後10行**の範囲を書きこむ
   - STEP2 範囲の中から根拠をさがして行番号を書く
   - STEP3 選択肢を「／」で区切り、区切りごとに○×、×の種類（A〜F）と根拠の行
   - STEP4 ×のない選択肢が答え
4. **解答・解説**：答え／範囲／根拠の行と本文／選択肢ごとに「どこが×か（下線）」「×の種類」「なぜ×か」
5. **解答用本文**：根拠に網かけ、各問の「前後10行」の範囲を本文の下に表示

×の種類：A 本文に書いていない／B 本文と反対／C 言いすぎ／D 人物のとりちがえ／E 理由・つながりがちがう／F 時・場面のずれ

## 学習アプリ（`web/`）

授業プリント全15回と**同じ問題**を、ブラウザで解けるアプリです。サーバーは不要で、`web/` フォルダをそのまま公開すれば動きます。

- **ホーム**：回ごとに「アプリで学習する」と「PDF（生徒用）」「PDF（解答つき）」のダウンロード
- **漢字・ことわざ・慣用句**：答えを入力して答え合わせ。別の書き方で合っているときは「○にする」で直せる
- **解き方ガイド**：消去法の4ステップと×の種類A〜F
- **長文**：本文はPDFと同じ縦書き・同じ行番号。問題ごとに
  1. 傍線部の行と「前後10行」の範囲を入力 → 正しければ本文の範囲に色がつく
  2. 根拠だと思う行をタップして印をつける
  3. 選択肢の区切りをタップして ○／× をつけ、×の種類を選ぶ
  4. 答えを選んで答え合わせ → 正解の根拠が本文に表示され、選択肢ごとに「×の部分を見つけられたか」がわかる
- **結果**：各テストの点数、長文の正解数、○×判断の正確さ、見落としやすい×の種類
- 進み具合はブラウザに自動保存され、「続きから学習」で再開できます。

```sh
python3 generate.py web        # 授業データ（web/data.js）と各回のPDF（web/pdf/）を作り直す
cd web && python3 -m http.server 8000   # → http://localhost:8000 で確認
```

**公開のしかた**：GitHub の Settings → Pages → Source を「GitHub Actions」にすると、
`main` ブランチに `web/` の変更が入るたびに自動で公開されます（`.github/workflows/pages.yml`）。
非公開リポジトリで GitHub Pages を使うには有料プランが必要です。Vercel や Netlify なら `web` フォルダを公開フォルダに指定するだけで使えます。

## PDFを作り直す・問題を変える

Python 3 と reportlab、日本語フォント（IPAexフォント推奨）が必要です。

```sh
pip install reportlab
sudo apt install fonts-ipaexfont        # Ubuntu/Debian の場合

git clone https://github.com/gokusan-maker/kokugo.git
cd kokugo
python3 generate.py                     # すべて作る（pdf/ に出力）
python3 generate.py anki --seed 2       # 暗記テストの出題を入れかえる
python3 generate.py anki --only kanji_kaki yoji --sets 5   # 分野をしぼって5回分
python3 generate.py chobun              # 長文読解だけ
python3 generate.py --list              # 分野キーと長文の一覧
```

- `--seed` を変えると、テストの出題順・組み合わせ・四字熟語や対義語で□にする字が変わります。
- フォントが見つからないときは、環境変数 `KOKUGO_FONT_MINCHO` / `KOKUGO_FONT_GOTHIC` に `.ttf` のパスを指定してください。

## 問題を追加する

- 暗記分野：`data/anki.py` に1行足すだけです。〈 〉で囲んだ部分が問われます。
- 長文：`data/passages.py` に本文と設問を追加します。本文中で
  `<u1>…</u1>` が傍線部①、`<e1a>…</e1a>` が問①の根拠です。
  生成時に **正解の根拠が傍線部の前後10行に入っているか自動で検査** し、外れているとエラーで知らせます。
  解説文の `{e1a}` は「◯行目『…』」、`{L:e1a}` は「◯行目」に自動で置きかわるので、行番号を手で書く必要はありません。

| --- | --- |
| `generate.py` | PDF・アプリ用データを作るコマンド |

| `kokugo_pdf/fonts.py` | フォント登録 |
