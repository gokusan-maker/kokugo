# アプリ開発ロードマップ（毎日1つずつ実装）

毎日の自動更新では、授業を1回分追加したあとで、このリストの「つぎにやること」の先頭から1つを実装します。
終わったら「できたこと」に移し、日付を書きます。新しく思いついた改善は「つぎにやること」の最後に足します。

各項目の実装ルール：
- `web/`（index.html・app.js・app.css）だけで動く静的なアプリのままにする（サーバー不要）
- 記録はこれまでどおり localStorage。既存のキー（`kokugo:v2:...`）の中身は変えない
- Playwright で画面を開いて動作を確かめ、エラーがないことを確認してからコミットする
- スマホ幅（390px）でもくずれないこと

## つぎにやること

1. **暗記カード（フラッシュカード）**：分野を選んで、カードをめくって覚える。覚えた／まだ を記録
2. **テストのタイマー**：漢字・語句テストに目標時間10分のタイマー（任意で開始）
3. **文字の大きさ切りかえ**：長文本文と問題の文字サイズを大・中・小で変えられる
4. **長文の「根拠さがし」ヒント**：ステップ2で、まちがえたときに範囲内の何段落目かをヒント表示
5. **×の種類の苦手分析**：これまでの長文で選んだ×の種類（A〜F）の集計を、結果ページと先生・保護者ページに表示
6. **ダークモード**：端末の設定に合わせて配色を切りかえる
7. **回のさがし方**：ホームで長文の種類（物語文・説明文…）や題名で回をしぼりこむ
8. **印刷用「まちがい直しプリント」**：まちがい直しページの問題を、そのまま印刷できる形にする
9. **冬休みコースの日付設定**：開始日を決めると、各日に日付が入り、今日の分がすぐ開ける
10. **記録のバックアップのお知らせ**：最後にファイルへ保存してから2週間たったら、ホームで書き出しをすすめる
